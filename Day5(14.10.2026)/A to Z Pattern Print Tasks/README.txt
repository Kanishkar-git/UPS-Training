Java A to Z Pattern Printing

- Contains one separate Java file for each letter A through Z.
- Each file is in package Patterns.
- Class names are PatternA, PatternB, ... PatternZ.
- Run the class for the letter you want and enter the size (l).
- The conditions from the supplied code were kept as written for the letters you provided.
- The original code did not include a V pattern, so PatternV.java uses a conventional V condition.

Example (from the folder containing the Patterns directory):
  javac Patterns/PatternA.java
  java Patterns.PatternA

Note: Some of the original conditions may create unusual-looking letters; they are intentionally preserved rather than redesigned.
